# 青岚 Qinglan

**Your Personal AI Companion & Second Brain**

> 让 AI 越来越懂你，而不是让你越来越懂如何使用 AI。

青岚（Qinglan）是一个开源的**个人 AI 系统**探索项目。

她不只是聊天窗口，也不只是执行指令的工具。我们希望青岚能够拥有自然的交流方式、持续积累的记忆，并在用户授权下理解和连接个人数字资产，逐渐成为一个**懂你、能思考、会行动的私人 AI 伙伴**。

## 为什么做青岚？

代码仓库、技术笔记、个人知识库、浏览器书签、工作文档、博客和灵光一现的想法，往往散落在不同的设备与应用中。

我们并不缺少保存信息的工具，缺少的是一个能够**理解、关联并使用这些信息的统一入口**。

青岚希望让你不再需要记住「文件放在哪里」「当时记录了什么」，而是可以自然地问：

- 「之前排查 Docker 容器网络问题，最后是怎么解决的？」
- 「我写过哪些关于个人 AI 的想法？哪些还没继续做？」
- 「帮我找到那个项目的部署方案，并说说它和现在的方案有什么不同。」
- 「整理一下最近零散的笔记，先给我建议，不要直接修改文件。」

这些是青岚希望逐步实现的使用场景，**并非当前已全部具备的功能**。

**智能大脑**提供语言理解和推理能力，支持选择本地或云端模型；**记忆系统**帮助青岚逐渐了解用户；**知识系统**连接散落的个人资料；**行动系统**则让她能够在授权范围内使用工具、完成实际任务。

四者共同服务于同一个目标：**让 AI 从回答问题，走向理解个人语境并协助行动。**

## 设计原则

- **以人为中心**：青岚应该逐渐适应用户，而不是让用户反复学习如何向 AI 下达指令。
- **自然交流**：既能认真讨论问题，也能轻松聊天；有稳定的表达风格，但不过度表演人格。
- **模型可替换**：个人记忆、知识与工具能力不绑定单一模型或服务商。
- **数据自主**：尽量连接和利用已有资料，而不是要求用户把所有信息搬进一个封闭系统；重要数据可备份、可迁移。
- **权限清晰**：访问文件和使用工具遵循授权与最小权限原则；高风险操作先确认，关键结果可追溯。
- **小步成长**：优先实现真实可用的场景，再逐步拓展能力与交互形态。
